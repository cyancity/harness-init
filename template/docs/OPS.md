# Operations

运维基线：可靠性 + CI/CD + 本地验收契约。

## Reliability Bar（项目扩展时填写）

- 启动与健康预期。
- 日志 / 指标 / 追踪约定。
- 超时、重试、退避规则。
- 关键路径的本地校验与流水线校验。
- 事故记录、常见失败模式与恢复步骤。

## Local Acceptance Contract（交付门）

- 每个可运行面只定义一条**规范的本地部署路径**，必须写明：
  - 启动真实本地依赖并执行迁移的命令；
  - 应交付 human 检查的 URL / 模拟器 / 入口点；
  - 最小就绪与功能冒烟检查；
  - 如何安全停止 / 重置环境。
- 纯文档或生成器改动可用一次性生成产物 + 链接与冒烟检查，不必拉起无关产品服务。

## Delivery Gate vs Merge Gate（两个独立闸门）

- **交付门**：本地 CI 等价检查 + 本地部署 + 冒烟 + 显式 human 验收 → 允许 commit / push / 开 PR / 进入下一特性。
- **合并门**：远端 CI 通过后 Agent 自行合并。排队或慢的 CI 异步继续并报告 pending；失败则任务回到实施态修复。

## Pipeline（真实栈确定后填写）

- 先建最小真实校验路径，再加构建产物、供应链扫描、发布与部署。
- 所有流水线入口与发布产物记录在此文件。
